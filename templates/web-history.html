History of the World Wide Web

Introduction

The World Wide Web is a system of linked pages and resources that people access through Web browsers. It was invented by Tim Berners-Lee at CERN in 1989. The Web uses the Internet to transfer information, but it is not the Internet itself. Technologies such as HTML, HTTP, and URLs form the foundation of the Web.

Key Milestones

1989 – Tim Berners-Lee Proposes the World Wide Web

While working at CERN, Tim Berners-Lee proposed a system for sharing and connecting information using hypertext.

Why it mattered: This proposal introduced the basic idea that later developed into the World Wide Web.

Source: CERN – The Birth of the Web

1990 – HTML, HTTP, and URLs Are Developed

Tim Berners-Lee developed the main technologies needed for the Web, including HTML, HTTP, and URLs.

Why it mattered: Together, these technologies made it possible to structure Web pages, identify their locations, and transfer them between computers.

Source: W3C – History of the Web

1990 – The First Browser, Web Server, and Website Are Created

Tim Berners-Lee created the first Web browser and editor, the first Web server, and the first website at CERN.

Why it mattered: These tools turned the Web from an idea into a working system that people could actually use.

Source: CERN – The Birth of the Web ; W3C – History

1991 – The Web Becomes Available to a Wider Audience

The Web began spreading outside CERN and became available to more people using the Internet.

Why it mattered: Researchers and other users outside CERN could begin accessing, using, and developing the Web.

Source: CERN – The Birth of the Web

1993 – CERN Makes Web Software Freely Available

On April 30, 1993, CERN placed the World Wide Web software in the public domain and later released it under an open licence.

Why it mattered: Developers and organizations could use and improve Web technology freely, which helped the Web grow quickly around the world.

Source: CERN – The Birth of the Web

1994 – W3C Is Founded

Tim Berners-Lee founded the World Wide Web Consortium, or W3C, at MIT in October 1994.

Why it mattered: W3C created a central organization for developing common Web standards and improving compatibility between websites, browsers, and devices.

Source: W3C – History

1996 – CSS Becomes a Web Standard

W3C published Cascading Style Sheets Level 1, or CSS1, as a recommendation in December 1996.

Why it mattered: CSS allowed developers to control the visual appearance of Web pages separately from their HTML structure, including fonts, colours, margins, and other presentation features.

Source: W3C – CSS1 Recommendation

1997 – HTML 4 Becomes a W3C Recommendation

W3C published HTML 4.0 as an official recommendation on December 18, 1997.

Why it mattered: HTML 4 improved support for forms, tables, scripts, style sheets, accessibility, and international content, while helping improve compatibility between Web technologies.

Source: W3C – HTML 4.0 Recommendation

2008 – The First Public Working Draft of HTML5 Is Published

W3C published the first public working draft of HTML5 on January 22, 2008.

Why it mattered: HTML5 was designed to modernize the Web and provide better support for applications, multimedia, and more consistent behaviour across browsers.

Source: W3C – HTML5 First Public Working Draft

2014 – HTML5 Becomes an Official W3C Recommendation

On October 28, 2014, HTML5 became an official W3C recommendation.

Why it mattered: HTML5 introduced and standardized features for modern Web applications, including new semantic elements and improved support for multimedia and browser-based applications.

Source: W3C – HTML5 Recommendation

2019 – WebAssembly Becomes a Web Standard

In December 2019, W3C made the WebAssembly Core Specification an official Web standard.

Why it mattered: WebAssembly allows high-performance code to run efficiently in Web browsers, making more powerful and complex Web applications possible.

Source: W3C – WebAssembly Recommendation

2023 – WCAG 2.2 Becomes a W3C Recommendation

On October 5, 2023, W3C published the Web Content Accessibility Guidelines 2.2 as a Web standard.

Why it mattered: WCAG 2.2 added new accessibility requirements designed to make Web content easier to use for people with different disabilities.

Source: W3C Web Accessibility Initiative – WCAG 2.2

2026 – The Web Continues to Evolve

HTML is currently maintained as a Living Standard by WHATWG. The specification continues to be updated as Web technology develops.

Why it matters: The Web is not a finished technology. Its standards continue to change as browsers, applications, devices, accessibility needs, and user expectations evolve.

Source: WHATWG – HTML Living Standard . The standard was still being actively updated in September 2026.

Three Key Web Technologies

  1. HTML – HyperText Markup Language

    HTML provides the structure and meaning of a Web page. It defines elements such as headings, paragraphs, links, images, forms, and sections.

  2. HTTP – Hypertext Transfer Protocol

    HTTP is used for communication between Web browsers and Web servers. A browser sends a request, and the server responds with the requested Web resource.

  3. URL – Uniform Resource Locator

    A URL identifies the location of a page or another resource on the Web and tells the browser where to find it.
