Introduction

The World Wide Web is a system used to access and share information through websites and web pages. Tim Berners-Lee created the Web while working at CERN. It uses technologies such as HTML, HTTP, and URLs to create, locate, and transfer web pages. The Web works through the Internet, but the Internet and the Web are not the same thing.

Key Milestones

1989 - Tim Berners-Lee Proposes the World Wide Web

Tim Berners-Lee wrote a proposal at CERN for a system that could connect and share information using hypertext.

Why it mattered: This proposal introduced the idea that eventually developed into the World Wide Web.

Source: CERN

1990 - HTML, HTTP, and URLs Are Developed

Tim Berners-Lee developed the main technologies needed for the Web, including HTML, HTTP, and URLs.

Why it mattered: Together, these technologies allowed people to create web pages, give them addresses, and send them between computers.

Source: W3C

1990 - First Web Browser, Server, and Website

At CERN, Tim Berners-Lee created the first web browser and editor, the first web server, and the first website.

Why it mattered: These developments provided the basic tools needed to create and access the Web.

Source: CERN

1991 - The Web Is Announced on the Internet

In August 1991, Tim Berners-Lee announced the World Wide Web software on Internet newsgroups.

Why it mattered: The announcement helped introduce the Web to people outside CERN.

Source: CERN

1993 - CERN Makes Web Software Freely Available

On April 30, 1993, CERN made the World Wide Web software freely available.

Why it mattered: This allowed more people to use and improve the Web, helping it grow rapidly.

Source: CERN

1993 - Mosaic Web Browser Is Released

The Mosaic browser was developed at the National Center for Supercomputing Applications.

Why it mattered: Mosaic made browsing the Web easier by providing a graphical interface that could show both text and images.

Source: CERN

1994 - W3C Is Founded

Tim Berners-Lee founded the World Wide Web Consortium, known as W3C.

Why it mattered: W3C develops Web standards to help websites and browsers work consistently together.

Source: W3C

Three Key Technologies

HTML - HyperText Markup Language

HTML is the language used to organize the content of a web page. It uses elements for things such as headings, paragraphs, links, and images.

HTTP - Hypertext Transfer Protocol

HTTP is the protocol used for communication between a web browser and a web server. It helps the browser request and receive web pages.

URL - Uniform Resource Locator

A URL is the address of a page or resource on the Web. It tells the browser where that resource can be found.
