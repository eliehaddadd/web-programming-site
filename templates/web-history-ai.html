Understanding the Web

The World Wide Web is a system of linked pages and resources that people access through Web browsers.

It was invented by Tim Berners-Lee at CERN in 1989. The Web uses the Internet to transfer information, but it is not the Internet itself.

Technologies such as HTML, HTTP, and URLs form the foundation of the Web.

Web Timeline

  1. 1989 - Tim Berners-Lee Proposes the World Wide Web

    While working at CERN, Tim Berners-Lee proposed a system for sharing and connecting information using hypertext.

    Why it mattered: This proposal introduced the basic idea that later developed into the World Wide Web.

    Source: CERN - The Birth of the Web

  2. 1990 - HTML, HTTP, and URLs Are Developed

    Tim Berners-Lee developed the main technologies needed for the Web, including HTML, HTTP, and URLs.

    Why it mattered: Together, these technologies made it possible to structure Web pages, identify their locations, and transfer them between computers.

    Source: W3C - History of the Web

  3. 1990 - The First Browser, Web Server, and Website Are Created

    Tim Berners-Lee created the first Web browser and editor, the first Web server, and the first website at CERN.

    Why it mattered: These tools turned the Web from an idea into a working system that people could actually use.

    Source: CERN - The Birth of the Web

  4. 1991 - The Web Becomes Available More Widely

    In 1991, the Web began becoming available to users outside CERN.

    Why it mattered: This allowed more people and institutions to begin using and developing the Web.

    Source: CERN - The Birth of the Web

  5. 1993 - CERN Makes Web Technology Freely Available

    CERN made the Web software freely available, allowing others to use and develop the technology.

    Why it mattered: Making the technology openly available helped the Web grow rapidly around the world.

    Source: CERN - The Birth of the Web

  6. 1994 - The World Wide Web Consortium Is Founded

    Tim Berners-Lee founded the World Wide Web Consortium, or W3C, at MIT.

    Why it mattered: The W3C helped develop common Web standards so browsers and websites could work more consistently.

    Source: W3C - History

  7. 1996 - CSS1 Becomes a W3C Recommendation

    CSS Level 1 became an official W3C Recommendation in 1996.

    Why it mattered: CSS allowed the visual appearance of Web pages to be separated from their HTML structure.

    Source: W3C - CSS1 Recommendation

  8. 1997 - HTML 4.0 Becomes a W3C Recommendation

    HTML 4.0 became a W3C Recommendation in 1997.

    Why it mattered: It expanded and standardized the features available for creating Web pages.

    Source: W3C - HTML 4.0 Recommendation

  9. 2008 - HTML5 Development Becomes Public

    The first public working draft of HTML5 was published in 2008.

    Why it mattered: HTML5 introduced work toward a more modern Web with stronger support for multimedia and interactive applications.

    Source: W3C - HTML5

  10. 2014 - HTML5 Becomes a W3C Recommendation

    HTML5 became an official W3C Recommendation in October 2014.

    Why it mattered: HTML5 became an important foundation for modern websites and Web applications.

    Source: W3C - HTML5 Recommendation

  11. 2019 - WebAssembly Becomes a Web Standard

    WebAssembly became a W3C Recommendation in 2019.

    Why it mattered: WebAssembly made it possible to run high-performance applications efficiently inside Web browsers.

    Source: W3C - WebAssembly Recommendation

  12. 2023 - WCAG 2.2 Is Published

    The Web Content Accessibility Guidelines 2.2 were published to improve accessibility for people with disabilities.

    Why it mattered: Accessibility standards help make websites usable by a wider range of people.

    Source: W3C - WCAG 2.2

  13. 2026 - The Web Today

    HTML continues to be maintained as a Living Standard by WHATWG and is regularly updated as the Web evolves.

    Why it mattered: The Web continues to develop instead of remaining fixed to one final version of HTML.

    Source: WHATWG - HTML Living Standard

Core Technologies of the Web

HTML
HTML provides the structure and meaning of content on a Web page.
HTTP
HTTP is the communication protocol used to transfer Web resources between browsers and servers.
URL
A URL identifies the location of a resource on the Web.
