The Development of the World Wide Web

Overview

The World Wide Web allows people to access and share information through websites and web pages. Tim Berners-Lee created the Web while working at CERN. Technologies such as HTML, HTTP, and URLs made it possible to create pages, transfer information, and locate resources online. The Web uses the Internet, but the two are not the same thing.

Web Timeline

  1. 1989 - Tim Berners-Lee Proposes the World Wide Web

    Tim Berners-Lee wrote a proposal at CERN describing a system for connecting and sharing information through hypertext.

    Why it mattered: The proposal introduced the idea that eventually developed into the World Wide Web.

    Reference: CERN

  2. 1990 - HTML, HTTP, and URLs Are Developed

    Tim Berners-Lee developed the main technologies required for the Web, including HTML, HTTP, and URLs.

    Why it mattered: These technologies allowed people to create web pages, give them addresses, and transfer them between computers.

    Reference: W3C

  3. 1990 - First Web Browser, Server, and Website

    At CERN, Tim Berners-Lee created the first web browser and editor, the first web server, and the first website.

    Why it mattered: These developments provided the basic tools needed to create and access information on the Web.

    Reference: CERN

  4. 1991 - The Web Is Announced on the Internet

    In August 1991, Tim Berners-Lee announced the World Wide Web software through Internet newsgroups.

    Why it mattered: This helped introduce the Web to people outside CERN and allowed more users to begin accessing it.

    Reference: CERN

  5. 1993 - CERN Makes Web Software Freely Available

    On April 30, 1993, CERN made the World Wide Web software freely available.

    Why it mattered: This allowed more people to use and improve Web technology, which helped the Web grow rapidly.

    Reference: CERN

  6. 1993 - Mosaic Web Browser Is Released

    The Mosaic browser was developed at the National Center for Supercomputing Applications.

    Why it mattered: Mosaic made browsing the Web easier by providing a graphical interface that could display both text and images.

    Reference: CERN

  7. 1994 - W3C Is Founded

    Tim Berners-Lee founded the World Wide Web Consortium, known as W3C.

    Why it mattered: W3C develops Web standards that help websites and browsers work consistently together.

    Reference: W3C

Important Web Technologies

HTML - HyperText Markup Language
HTML is the language used to organize the content of a web page. It uses elements for headings, paragraphs, links, images, and other page content.
HTTP - Hypertext Transfer Protocol
HTTP is the protocol used for communication between a web browser and a web server. It allows the browser to request and receive web pages.
URL - Uniform Resource Locator
A URL is the address of a page or resource on the Web. It tells the browser where that resource can be found.
